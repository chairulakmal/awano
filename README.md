# Awano

**Awano** is a multi-team support desk web app. Customers, recruiters, and field agents submit tickets; support staff triage and resolve them; managers oversee the queue and manage users. A super-admin role can create isolated **teams** for demos (e.g. different credential sets per job application).

Built as a portfolio fullstack project: **Next.js**, **TypeScript**, **Prisma**, and **PostgreSQL**.

## Status

Early stage — product specification and project setup. Application code is not implemented yet.
