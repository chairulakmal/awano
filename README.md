# Awano

**Awano** helps a company handle support requests in one place.

People outside the company—such as **customers**, **recruiters**, or **staff working in the field**—can open a ticket when they need help. **Support agents** pick up tickets, reply, and track progress. **Managers** can oversee the queue, reassign work, and manage who has access.

Each **team** in Awano is a separate workspace (for example, one company or one business unit). People in one team only see that team’s tickets and users, so data stays isolated when you run more than one group on the same system.

## Who it’s for

- **Requesters** — submit issues and follow the conversation on their own tickets  
- **Support** — view the team inbox, assign tickets, reply, and add internal notes the requester cannot see  
- **Managers** — handle escalations, close or reopen tickets, and manage users and categories  
- **Super admin** — create teams and set up accounts (useful for trials, staging, or hosting multiple organizations)

## Tech

Awano is a web application built with **Next.js**, **TypeScript**, **Prisma**, and **PostgreSQL**.

## Status

The project is in early development. The [product spec](docs/SUPPORT_DESK_SPEC.md) describes roles, workflows, and planned screens; the app itself is not built yet.
